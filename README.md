# ひき算の筆算

小学算数の「ひき算の筆算」を、くらいごとの操作に分けて練習する静的Webアプリです。

## レベル
- LEVEL 1：2けた−2けた、くり下がりなし
- LEVEL 2：2けた−2けた、一のくらいのくり下がりを見分ける
- LEVEL 3：2けた−2けた、二つのくらいのくり下がりを見分ける
- LEVEL 4：3けたの筆算

## 学習の流れ
LEVEL 1は「右から計算する → 答えを書く」。LEVEL 2以降は、毎回「くり下がりがある／なし」を判断してから答えを書きます。児童が数字を入力して正誤を確かめ、正解した数字だけ筆算の盤面に反映されます。

外部APIやサーバーは使用せず、記録は端末の localStorage に保存します。
