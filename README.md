# ひき算の筆算

小学算数の「ひき算の筆算」を、くらいごとの操作に分けて練習する静的Webアプリです。

## レベル

- LEVEL 1：2けた−2けた、くり下がりなし
- LEVEL 2：2けた−2けた、くり下がりあり
- LEVEL 3：3けた−2けた、百の位を1に固定。0をまたぐくり下がりを中心に、一の位のくり下がりなしも混ぜる
- LEVEL 4：3けた−2けた、さまざまなくり下がりを扱う

各レベルでは、そのレベルの問題を中心にしながら、それ以前に学習した問題もときどき復習として出題します。

## 学習の流れ

LEVEL 1は「右から計算する → 答えを書く」。

LEVEL 2以降は、まず「くり下がりがある／なし」を判断します。くり下がりがある問題では、必要に応じて「十のくらいからか、百のくらいからか」を考えてから計算します。

筆算の途中で、実際の手書きに近い形で「10をもらう」「もとの数字を1減らす」などの操作を段階的に確認できるようにしています。元の数字そのものを書き換えるのではなく、上の補助欄にくり下がりを表示します。

## バトル

ナビキャラクターとモンスターで取り組める「バトル」と「タイムアタック」を搭載しています。

正解すると攻撃、5コンボごとにスペシャル攻撃、まちがえるとミスとして記録されます。ナビキャラクターの攻撃・ダメージ・スペシャル画像を使って、学習の流れを妨げない範囲で演出します。

## データ・技術

- HTML / CSS / JavaScript の静的Webアプリ
- GitHub Pagesで公開可能
- 外部API・サーバー・データベースは使用しません
- 学習記録・設定は端末の localStorage に保存します
- 音はミュート切り替えに対応しています
- ナビキャラクター・モンスターなどの画像は、指定した公開アセットを参照します

## 利用について

学校・家庭での非営利の学習利用を想定しています。
